How this app fits

Names is the simple consumer-facing Pipe-Works app. It does not create corpora, annotate syllables, or manage package imports. Those remain part of the creator workbench and operator workflows.

This app assumes prepared package data already exists in the runtime API. You pick the class, package, and syllable mode you want, preview results, and keep the names you like.

  • Use the Generate tab to queue one or more selections and preview names.
  • Queue both First Name and Last Name to unlock combination previews.
  • Use Favorites to keep names across sessions without opening the creator workbench.
